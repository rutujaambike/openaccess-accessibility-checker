# Contributing

Choose one issue at a time and comment to coordinate with maintainers. Fork the repo, create a branch named `issue-N-short-description`, make a focused change, run `python -m unittest discover -s tests -v`, and open a PR. Explain what changed, how to reproduce it, and what you tested. For UI changes, include a screenshot and check the interface using only the keyboard. Avoid adding claims of WCAG compliance or phishing safety based solely on automated results. Never commit tokens, Gmail app passwords, private URL histories, or personal email content.
